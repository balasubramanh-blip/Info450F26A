# INFO 450: Systems Analysis and Design
**Virginia Commonwealth University (VCU) | School of Business**

Welcome to the repository for **INFO 450: Systems Analysis and Design** at VCU. This repository contains course materials, project deliverables, assignments, and notes documenting the end-to-end process of analyzing, designing, and specifying modern information systems.

---

## 📌 Course Overview

INFO 450 focuses on the concepts, methodologies, tools, and techniques required to analyze business problems and design computer-based information systems. The course emphasizes both traditional System Development Life Cycle (SDLC) methodologies and modern Agile/Scrum practices.

### Key Learning Objectives
* **Systems Development Life Cycle (SDLC):** Master planning, analysis, design, implementation, and maintenance phases.
* **Requirements Engineering:** Elicit, analyze, document, and manage functional and non-functional system requirements.
* **Process & Data Modeling:** Create Data Flow Diagrams (DFDs), Entity-Relationship Diagrams (ERDs), and UML diagrams (Use Case, Class, Sequence Diagrams).
* **Agile & Scrum Methodologies:** Formulate user stories, acceptance criteria, and backlog prioritization techniques.
* **Feasibility & Risk Analysis:** Evaluate technical, operational, schedule, and economic feasibility (ROI, NPV, Payback Period).
* **UI/UX & System Architecture:** Design user interfaces, input/output controls, and system architecture blueprints.
